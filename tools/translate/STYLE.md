# 神無ノ鳥(칸나기의 새) 한글 패치 번역 가이드 (에이전트 필독)

일본어 VN 대사를 자연스러운 한국어(CP949) 구어체로 번역한다. 아래를 **엄격히** 따른다.

## A. 표기 규칙 (엔진 제약 — 반드시)

**기호·숫자는 ASCII 로 쓴다.** 주입기가 알아서 전각으로 바꾼다 —
띄어쓰기는 일반 스페이스, 마침표는 `.`, 쉼표는 `,`, 그 밖에 `123` `!` `?` `-` `...`
전부 그냥 친다. 전각을 직접 치려다 나는 오타가 훨씬 잦아서 이렇게 바꿨다.

```
안녕 하세요! 123...   →   안녕　하세요！　１２３…      (주입기가 변환)
```

**단, 괄호류는 원문 형태 그대로 쓴다** — `「」` `『』` `【】` `（）`.
ASCII `"` `'` `(` `)` 로 바꿔 쓰지 말 것. 여는 괄호는 엔진이 자동으로 넣으므로
번역문에 **직접 넣지 않는다**(아래 종결부 규칙 참조).

`。`·`、`도 원문 그대로 둘 수 있다 — 주입 후처리가 `．`·`，`로 바꾼다. ASCII `.`·`,`
로 써도 결과는 같다.

> **왜 ASCII 를 써도 되나** — 엔진은 0x80 미만을 전부 커맨드로 소비하므로 화면에
> 나갈 글자에 ASCII 가 남으면 안 된다. 그래서 주입기가 **원문에서 커맨드를 먼저
> 골라낸 뒤**(문장 앞뒤에 붙는 `*`·`%` 같은 것) 나머지 ASCII 만 전각으로 바꾼다.
> 커맨드가 유실되면 `ujyu filter check` 와 `ujyu inject check` 가 바이트 단위로 잡는다.

전각으로 직접 써도 그대로 통과한다 — 아래 B~D 의 예시가 전각인 것은 예전 표기라
그렇고, 기존 번역분도 전각 그대로 두면 된다. 새로 쓸 때 ASCII 가 편하다는 뜻이다.

- **대사(dlg) 종결부는 원문 그대로 유지**: 끝의 `」%` 또는 독백의 `）`. **여는 `「`·`（`는 절대 넣지 않는다**(엔진 자동). 번역문은 내용 + 닫는 부호만.
  - 예) `ダメだっ！」%` → `안 돼!」%`  /  독백 `…どう答えよう？）` → `…뭐라고 대답하지?）`
  - 종결부의 `」%`·`）`·`*v` 는 **원문 그대로** 복사한다. 이건 커맨드라 ASCII 로 남아야 한다.
- **나레이션(narr)**: 맨 앞 전각공백 1개로 시작(들여쓰기), 끝 `。`.
  - 예) `　少年は、目を閉じた。` → `　소년은, 눈을 감았다.`  (선두 들여쓰기는 전각공백 그대로)
- 숫자: 날짜는 숫자 그대로(`６月１日`→`6월 1일`, 주입기가 전각화), 수량은 한글로(`１ヶ月`→`한 달`).
- **후리가나 `【...】` 제거** — 확정 표기만 남긴다 (`綿貫　琉宇【わたぬき　るう】`→`와타누키　루우`, `常闇【とこやみ】`→`상암`).

## B. 인물·말투 (speaker 필드에 맞춰 통일)
- **이카루(イカル)**: 주인공. 거친 소년 반말. 1인칭 `나`. `～잖아/～란　말이야/～거든/～라고`. 직설·다혈질.
- **하칸(ハッカン)**: 이카루의 형 같은 존재. 짓궂은 반말. 1인칭 `나`. `～냐/～잖아/～라니까/～다고`. 이카루를 `꼬맹이/애송이`로 놀림.
- **렌자크(レンジャク)**: 과묵·냉정한 문어체. 1인칭 `나`. `～다/～인가/～군/～겠지/～하지`. 정중하고 딱딱.
- **와타누키 루우(綿貫琉宇)**: 회수 대상 소년. 소심하고 더듬거림. 어른에겐 존댓말, 이카루에겐 조심스런 반말.
- **후카마치 야스나리(深町康哉)**: 루우의 삼촌. 온화한 어른 말투(부드러운 존댓말/반존대).
- **마나베 아키히토(真部章仁)**: 후카마치에게 적의. 퉁명·무뚝뚝한 반말.
- **미리스(みりす)**: 루우가 기르는 햄스터=**루우 속마음 대변**. 대사는 울음소리뿐. `うじゅ→우쥬`, `ぢゅ→쥬`. 길이·부호 원문대로 보존(`うじゅっ！`→`우쥬앗！`, `うじゅー…`→`우쥬—…`).
- 그 외 화자는 speaker와 문맥에 맞는 자연스러운 말투로.

## E. 작업 지침
- 입력 파일에서 **`◆미번역` 표시가 붙은 항목만** 번역한다.
- 이미 `kr:` 값이 있는 항목은 **문맥·스타일 참고용**이며 절대 바꾸지 않는다.
- 원문 뉘앙스·말투를 보존하되, 직역투를 피하고 자연스러운 한국어로.
