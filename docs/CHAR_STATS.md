# 문자 통계 — 원문(jp)

**원작 시나리오가 실제로 쓰는 글자의 목록과 빈도.** 게임에서 추출한 원문을
그대로 센 것이고, 번역 결과와는 무관하다.

쓸 데:

- **폰트에 어떤 글리프를 넣어야 하는지** — 여기 없는 글자는 준비할 필요가 없다.
- **CP949 로 옮길 수 있는지** — 아래 "인코딩 불가" 목록이 그대로 `ujyu jpmap` 의
  대상이다(사용자 정의 영역에 실어 나른다).
- 번역하지 않고 원문으로 남길 대목이 있을 때 그 글자들이 화면에 나오는지 가늠.

`ujyu filter chars --jp-only` 로 다시 만든다. 손으로 고치지 말 것.
본문은 표시되는 글자만 세고, 대사 끝 제어코드(`」%` 의 `%` 등)는 뺐다.
