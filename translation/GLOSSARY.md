# 고유명사 표기 표 (Glossary)

> **게임 제목: 「神無ノ鳥」= 칸나기의 새** (Studio Miris / team L←→R, 2002-11-29 발매).
> 번역 일관성용 **살아있는 문서**. 공식 사이트(archive) + VNDB v2506 반영. 표기 확정 전은 `※`.

## 표기 원칙
- 인명·지명 등 일본어 고유명사는 **발음 기준 음역** (かんなぎ → 칸나기, ふかまち → 후카마치).
- 작품 핵심어 `神無`의 읽기는 かんなぎ → **칸나기**.
- 인명 읽기는 공식 페이지 파일명(로마자)으로 확정된 것 위주. 미확정은 ※.
- **후리가나 `【】` 는 번역문에 쓰지 않는다.** 일반 어휘는 그냥 번역하고, 고유명사는
  **가나 읽기 / 한자어 독음 중 하나를 골라 확정**한다 (`번역【읽기】` 병기 스타일 금지).
  확정 예: `神無`=칸나기(가나 읽기), `常闇`=**상암**(한자어 독음), `紗`=우스기누, `斑鳩`=이카루.

## 후리가나 확정 표기

원문에 `한자【よみ】` 형태로 **읽기가 박혀 있는** 어구 (전 시나리오 자동 추출, 26종).
읽기가 원문에 있으므로 음역의 **1차 근거**다. 고유명사인지 단순 난독 한자인지는
**주변 문맥으로 판별**했다.

## 메모
- 칸나기의 새들은 **새 이름**: 이카루(밀화부리), 렌자크(여새), 하칸(백한), セキレイ(세키레이) 등.
- `斑鳩` 는 후리가나 `【いかる】` 로 **이카루** 확정 (이카루가 아님). 주인공과 같은 읽기.
- `紗` 는 `【うすぎぬ】` = **우스기누**. 「名は、紗といいます」로 본인이 밝힌다.
- `山子【やまこ】` 는 인명이 아니라 **요괴 이름** — 「山子という妖怪の子孫。『死』を予知できる人々」.
  루우 일족(죽음을 예지하는 사람들)의 유래다.
- 인간 인물은 **성우 캐스팅**이 공식 확정(CHARACTERS.md 참조).
- ※표시 읽기는 후리가나/음성으로 검수 확정 필요.
